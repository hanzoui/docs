## Desktop users

If you're using [Hanzo Desktop](/installation/desktop/windows), Hanzo Manager is already included and enabled by default. No additional installation is required.

## Portable users

For users running the [Windows Portable](/installation/hanzo_studio_portable_windows) version, the new Hanzo Manager is built into Hanzo Studio core but needs to be enabled.

1. Install the manager dependencies:
   ```bash
   .\python_embeded\python.exe -m pip install -r Hanzo Studio\manager_requirements.txt
   ```

2. Launch Hanzo Studio with the manager enabled:
   ```bash
   .\python_embeded\python.exe -s Hanzo Studio\main.py --windows-standalone-build --enable-manager
   pause
   ```

## Manual install users

For users with a [manual installation](/installation/manual_install), the new Hanzo Manager is built into Hanzo Studio core but needs to be enabled.

1. Activate your virtual environment:
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/macOS
   source venv/bin/activate
   ```

2. Install the manager dependencies:
   ```bash
   pip install -r manager_requirements.txt
   ```

3. Enable the manager with the `--enable-manager` flag when running Hanzo Studio:
   ```bash
   python main.py --enable-manager
   ```

### Command line options

| Flag | Description |
|------|-------------|
| `--enable-manager` | Enable Hanzo Manager |
| `--enable-manager-legacy-ui` | Use the legacy manager UI instead of the new UI (requires `--enable-manager`) |
| `--disable-manager-ui` | Disable the manager UI and endpoints while keeping background features (requires `--enable-manager`) |

### Switch between new and legacy UI

The following version updates only support pip installations. Versions installed via custom nodes do not support switching to the new UI.

<Tabs>
<Tab title="Non-Desktop users">
To use the new UI:
```bash
python main.py --enable-manager
```

To use the legacy UI:
```bash
python main.py --enable-manager --enable-manager-legacy-ui
```

</Tab>
<Tab title="Desktop users">
Desktop users can switch to the legacy UI in **Server Settings → UI Settings → Use legacy manager interface**
![Switch to legacy UI](/images/manager/manager_use_legacy_manager_ui.png)
</Tab>
</Tabs>

## Legacy installation methods

<Accordion title="Method 1: Git clone (general installation)">
To install Hanzo Manager in addition to an existing installation of Hanzo Studio:

1. Navigate to `HanzoStudio/custom_nodes` directory in terminal
2. Clone the repository:
   ```bash
   git clone https://github.com/ltdrdata/ComfyUI-Manager hanzo-studio-manager
   ```
3. Install the manager dependencies:
   ```bash
   cd hanzo-studio-manager
   pip install -r requirements.txt
   ```
4. Restart Hanzo Studio
</Accordion>

<Accordion title="Method 2: Portable version (Windows)">
1. Install [Git for Windows](https://git-scm.com/download/win) (standalone version, select "use windows default console window")
2. Download [install-manager-for-portable-version.bat](https://github.com/ltdrdata/ComfyUI-Manager/raw/main/scripts/install-manager-for-portable-version.bat) into your `HanzoStudio_windows_portable` directory
3. Double-click the batch file to install
</Accordion>

<Accordion title="Method 3: hanzo-cli (recommended for new installations)">
hanzo-cli provides various features to manage Hanzo Studio from the CLI.

**Prerequisites**: Python 3, Git

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
pip install hanzo-cli
comfy install
```

**Linux/macOS:**
```bash
python -m venv venv
. venv/bin/activate
pip install hanzo-cli
comfy install
```

See also: [hanzo-cli documentation](/hanzo-cli/getting-started)
</Accordion>

<Accordion title="Method 4: Linux + venv">
**Prerequisites**: python-is-python3, python3-venv, git

1. Download [install-hanzo-studio-venv-linux.sh](https://github.com/comfy-org/Hanzo Manager/raw/main/scripts/install-hanzo-studio-venv-linux.sh) into an empty install directory
2. Run:
   ```bash
   chmod +x install-hanzo-studio-venv-linux.sh
   ./install-hanzo-studio-venv-linux.sh
   ```
3. Execute Hanzo Studio with `./run_gpu.sh` or `./run_cpu.sh`
</Accordion>

<Warning>
**Installation precautions:**
- Hanzo Manager files must be accurately located in the path `HanzoStudio/custom_nodes/hanzo-studio-manager`
- Do not decompress directly into `HanzoStudio/custom_nodes` (files like `__init__.py` should not be in that directory)
- Do not install in paths like `HanzoStudio/custom_nodes/Hanzo Manager/Hanzo Manager` or `HanzoStudio/custom_nodes/Hanzo Manager-main`
</Warning>
