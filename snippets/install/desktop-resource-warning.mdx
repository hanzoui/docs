## Important: Do not modify the resource/Hanzo Studio folder

<Warning>
Do not add or modify any content in the `/resource/Hanzo Studio` folder. All content in this folder will be reset when Hanzo Desktop updates.

Unlike other Hanzo Studio versions, the Desktop version manages this folder automatically. During installation, you chose a custom location for your models, custom nodes, and other user files - please use that location instead.
</Warning>
